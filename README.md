# Taiwan-Stock-Report

自動化台股市場廣度簡報存放庫。透過 [Taiwan-Stock MCP](https://claude.ai) 連接器定期查詢台股即時／日收盤資料，
於台股交易時段（約 09:00–13:30，台北時間）每半小時至一小時產出一份市場廣度簡報，並以 Markdown 格式提交存檔。

## 目錄結構

```
<YYYY-MM-DD>/
  <HHMM>.md   # 單次簡報，檔名為台北時間 24 小時制（無冒號）
```

例如 `2026-08-14/1321.md` 為 2026-08-14 13:21（台北時間）產出的簡報。

## 簡報內容

每份簡報通常包含：

- 產出時間、資料交易日（開盤/收盤、盤中/收盤狀態）
- 市場廣度數據：上漲／下跌／平盤家數、漲跌家數比、平均漲跌幅
- 漲幅／跌幅前五名個股
- 成交量異常放大個股
- 若資料來源或連接器故障，會清楚註明無法產出的項目、原因與任何權宜替代資料，並附上建議

簡報以繁體中文撰寫（早期少數簡報為英文）。

## 已知問題

`realtime_price` 查詢層自 2026-08-06 起持續發生後端 SQL 參數綁定錯誤，導致多項即時工具
（`get_realtime_market_breadth`、`get_realtime_top_movers`、`get_realtime_volume_surge` 等）無法使用。
詳細狀況與逐次追蹤記錄於各簡報檔案及 git commit 歷史中。

## 開發須知

本存放庫僅存放自動產出的 Markdown 報告，不含應用程式碼，無需建置、測試或 lint 流程。
詳細撰寫規範請見 [CLAUDE.md](./CLAUDE.md)。
