# Taiwan-Stock-Report

自動化台股市場廣度簡報存放庫。透過 [Taiwan-Stock MCP](https://claude.ai) 連接器定期查詢台股即時／日收盤資料，
於台股交易時段（約 09:00–13:30，台北時間）每半小時至一小時產出一份市場廣度簡報，並以 Markdown 格式提交存檔。

## 目錄結構

```
<YYYY-MM-DD>/
  <HHMM>.md   # 單次簡報，檔名為台北時間 24 小時制（無冒號）
```

例如 `2026-11-20/1415.md` 為 2026-11-20 14:15（台北時間）產出的簡報。

## 報告保存

存放庫目前只保留 2026-11 起的報告。2026-11-23 清除了 2026-08-05 至 2026-10-30 的舊報告（共 553 份），
這些報告仍保留在 git 歷史中，可從清除前的最後一個 commit `39265fc` 還原：

```sh
git show 39265fc:2026-10-30/1416.md      # 檢視單一舊報告
git checkout 39265fc -- 2026-10-30       # 還原整個日期資料夾
```

## 簡報內容

每份簡報通常包含：

- 產出時間、資料交易日（開盤/收盤、盤中/收盤狀態）
- 市場廣度數據：上漲／下跌／平盤家數、漲跌家數比、平均漲跌幅
- 漲幅／跌幅前五名個股
- 成交量異常放大個股
- 若資料來源或連接器故障，會清楚註明無法產出的項目、原因與任何權宜替代資料，並附上建議

簡報以繁體中文撰寫（早期少數簡報為英文）。
